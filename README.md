# dea-c01-lambda-vpc-s3-secure-file-transfer-using-gateway-endpoints
This repository demonstrates a secure and cost-effective solution for transferring files from a legacy SFTP system to Amazon S3 using AWS Lambda in a VPC. It resolves S3 timeout issues by configuring a VPC Gateway Endpoint for Amazon S3, eliminating the need for internet or NAT gateways, aligned with DEA-C01 best practices.
