│                                                                 │

│  • No long-term credentials                                   │
│  • Service accounts / managed identities                      │
│                                                                 │
│  Layer 4: ENCRYPTION                                           │
│  • TLS/HTTPS in transit                                       │
│  • SSH/SFTP encryption                                        │
│  • AES-256 encryption at rest                                │
│                                                                 │
│  Layer 5: SECRETS MANAGEMENT                                   │
│  • No hardcoded credentials                                   │
│  • Encrypted secrets vault                                    │
│  • Automatic key rotation                                     │
│                                                                 │

Key Cost Optimization Strategies:
1. Use Private Endpoints (no NAT gateway)
2. Serverless compute (pay-per-use, no idle costs)
3. Storage lifecycle policies (automatic tiering)
4. Log retention policies (7-30 days)
5. Right-sized function memory (512MB)
