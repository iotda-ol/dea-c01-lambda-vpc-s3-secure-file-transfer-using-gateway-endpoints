│  DATA FLOW (Step-by-Step)
│  ═════════════════════════
│
│  1. Scheduler triggers serverless function (EventBridge/Cloud Scheduler/Logic Apps)
│  2. Function starts in VPC private subnet
│  3. Function assumes IAM role/service account/managed identity
│  4. Function retrieves SFTP credentials from Secret Manager
│  5. Function connects to SFTP server over internet (port 22, SSH protocol)
│  6. Function downloads file(s) from SFTP server to function memory
│  7. Function uploads file(s) to Object Storage via Private Endpoint (port 443, HTTPS)
│  8. Object Storage encrypts file(s) with AES-256 at rest
│  9. Lifecycle policies manage storage class transitions for cost optimization
│ 10. Function logs all operations to centralized logging service
│ 11. Monitoring service collects metrics (invocations, errors, duration)
│ 12. If error threshold exceeded, alerting service sends notifications
│ 13. Function execution completes
